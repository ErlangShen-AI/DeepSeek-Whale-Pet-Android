# 小鲸鱼桌宠 Android

把 [DeepSeek-Balance-Whale-Widget](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget) 这只住在界面右下角的小鲸鱼，
移植成原生 Android 的悬浮桌宠。鲸鱼可以拖到屏幕任意位置、贴边吸附、按压回弹，气泡里实时显示 DeepSeek 账户余额与今日用量。

原项目由 [MeteorNOX](https://github.com/MeteorNOX) 制作，本仓库只是换了一个宿主：鲸鱼形象、气泡几何与描边配色、
随机台词与权重、峰谷定价表与时段判定、记账规则都来自原作者，Android 端做的是悬浮窗、触摸与动画的重新实现。
详细的承接关系见「[与原挂件的对应关系](#与原挂件的对应关系)」与「[致谢与许可](#致谢与许可)」。

## 特性

- 悬浮桌宠：拖动时与手指一比一跟随，坐标夹在系统栏以内的安全区，松手按落点吸附到最近的边
- 左缘吸附整体水平镜像，气泡文字同步反向翻转后仍可读
- 按压 Q 弹玩偶效果，以画布底边中心为原点，按下时底部坐标不变
- 代码绘制的气泡：大椭圆、尾巴与两个小圆沿用原挂件几何，文字三行随气泡开合淡入
- 余额：每 60 秒自动刷新（可调 20 至 600 秒），点击鲸鱼立即刷新，余额变化时数字滚动
- 上一轮对话消耗：刷新时检测到余额下降即弹出消耗气泡，金额取绝对值并以红色显示
- 今日已用：小鲸鱼记账与实时令牌两种模式，令牌模式按峰谷定价换算
- 自定义余额：没有密钥时用任意文本替代余额与今日已用，也可以整体隐藏余额相关内容只留台词
- 随机台词：点击气泡切换台词，含时段提示、动态图与卖萌台词，按权重抽取
- 音效：小黄鸭与音效1两套按压音效，可关闭、可调音量、可试听
- 深浅色主题、系统字号缩放与旋转自适应

## 交互

| 操作 | 行为 |
| --- | --- |
| 单击鲸鱼 | 刷新余额并弹出气泡，气泡已打开时只重新计时 |
| 单击气泡 | 第一次切到随机台词，再点一次收起；消耗气泡点击直接收起 |
| 拖动鲸鱼 | 移动桌宠，松手按落点吸附，贴左缘整体镜像 |
| 通知栏条目 | 打开设置、立即刷新、收起桌宠 |
| 应用图标 | 打开设置界面 |

桌宠本身不承载打开设置的手势，页面内的使用说明与此一致：没有双击与长按动作。
拖动越界即停在安全区边界，吸附按松手时的落点判定，横向落在屏幕左右各四分之一内贴对应边，纵向同理，其余情况停在原地。
气泡自动关闭时间可在设置中调整，设为 0 秒表示不自动收起。

## 开发方式

这个仓库的代码由 Android 端的 [OpenMinis](https://github.com/OpenMinis/OpenMinis) 编写，
配合 GitHub Actions 完成编译、签名与发布，整个项目是纯 Vibe Coding 的产物：
需求用自然语言描述，代码、注释与文档由 AI 生成，人在设备上验证手感与效果。

## 构建

仓库已配置 GitHub Actions：每天定时构建一次，也可以在 Actions 页面手动触发 `Android` 工作流。
产物为 `DeepSeek-Whale-Pet.apk`，既作为 artifact 上传，也以 `latest` 标签更新发布页，
官网 [Whale-Pet-web](https://github.com/ErlangShen-AI/Whale-Pet-web) 每天同步这一份安装包供页面直接下载。
工作流先运行单元测试，再编译发布包，最后校验签名主体不是 `CN=Android Debug`、
清单里没有 `application-debuggable`，任一不通过即失败。
`cleanup.yml` 每天清理历史运行，每个工作流只保留最新一次。

本地构建要求：

- JDK 25 及以上，根构建脚本会在低于该版本时直接报错
- Android SDK Platform 36，`compileSdk` 与 `targetSdk` 均为 36，`minSdk` 为 26
- Gradle 9.7.1，由 wrapper 提供
- 发布签名从 `WHALE_KEYSTORE_PATH` 等环境变量读取，缺少密钥时构建不带签名的发布包

```bash
./gradlew :app:test
./gradlew :app:assembleDebug
```

## 安装

1. 从[官网](https://erlangshen-ai.github.io/Whale-Pet-web/)下载 APK 并安装
2. 打开应用，填写「API Key」（`sk-` 开头）
3. 点击「悬浮窗权限」按提示授权
4. 打开「显示桌宠」，鲸鱼会从屏幕边缘滑入

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `SYSTEM_ALERT_WINDOW` | 在其他应用上层绘制桌宠 |
| `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_SPECIAL_USE` | 保持桌宠常驻并显示状态通知 |
| `POST_NOTIFICATIONS` | 展示余额状态通知 |
| `INTERNET` | 请求余额与用量接口 |
| `RECEIVE_BOOT_COMPLETED` | 开机后按设置恢复桌宠 |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | 由用户决定是否加入电池优化白名单 |

API Key 与平台令牌只保存在应用私有存储中，仅用于请求 DeepSeek 接口。

## 触摸与窗口

桌宠由两个矩形悬浮窗叠成，窗口的位置与尺寸每帧按画布几何结算：

- 每个窗口的矩形取「内容的实际绘制范围」与「按压形变后的范围」的并集，再按画布单位加一圈余量，
  余量覆盖形变缓动的过冲与坐标取整；镜像翻转进行中取左右两侧的并集，翻转不会被窗口裁掉
- 窗口之内再做一次形状判定：鲸鱼读贴图透明度，气泡读三个图形（主体、尾巴、两个小圆）的绘制掩码，
  透明像素不响应
- 气泡窗口叠在鲸鱼之上，落在其中的触摸先按气泡形状判定；没有命中气泡但命中鲸鱼轮廓时交给鲸鱼处理，
  因此气泡展开期间鲸鱼仍可抓取
- 气泡淡出与等待移除期间整窗不可触摸，这一段的触摸回到鲸鱼

窗口内没有绘制到的像素（外框余量、鱼鳍之间的空隙、气泡外接矩形的四个角）不会继续传给下层应用，
这是单矩形窗口的固有限制。

窗口在系统里丢失时会重新挂上：服务启动、系统配置变化、从设置页返回前台这三处都会重新结算屏幕几何、
按锚点复位尺寸与位置、补齐缺失的窗口并强制重绘；气泡窗口丢失时同时收起气泡状态，保持内外一致。

## 设计说明

界面按照 Apple 设计规范组织，落点在以下几条：

- 反馈发生在按下瞬间：按压形变与按压音效同时开始，松手音效按按压样本的剩余时长排程
- 按压形变用时 0.22 秒的 CSS `cubic-bezier(.34,1.56,.64,1)`，先过冲再回到原尺寸
- 位置结算与尺寸变化走 0.16 秒与 0.28 秒的 CSS `ease` 补间；拖动期间坐标直接跟随手指，不插值
- 拖动越界即停在安全区边界，不做阻尼；吸附目标取自松手时的落点，不参与速度投影
- 动画由 Choreographer 推帧，只在有动画进行时请求下一帧，静止后停掉回调并落盘位置
- 气泡三个图形错峰弹出，文字延后 0.36 秒淡入，内容切换先淡出、替换、再淡入
- 系统关闭动画后，位移、形变与数字滚动改为直接落位，气泡文字淡入不再等待延迟
- 字号越大字距越紧、行高越紧，字重承担层级
- 气泡内容只由内容入口给出：隐藏余额、自定义余额、自定义今日已用、显示今日已用这些开关只改变取到的文本，
  气泡、时段台词、设置页预览与通知栏消费同一份结果，不存在各自判断的分支

尺寸只有三个来源，没有按屏幕写死的像素值：

- **界面**：间距、圆角、行高、发丝线全部是 `Metrics.unit` 的倍数，`unit` 取屏幕短边的比例并夹在 dp 上下限之间；
  文字走 `sp`，再叠加屏幕尺寸系数（0.92–1.18）与系统字号设置
- **桌宠**：绘制全部以 1026x1026 的画布单位为基准，屏幕像素由 `unit = 画布边长 / 1026` 换算；
  画布边长 = `clamp(122dp, min(250dp, 屏幕短边 x 0.28) x 缩放倍率, 625dp) x 屏幕密度`，
  上下限是 dp 而非像素，因此在任意密度上都得到相同的物理尺寸
- **窗口**：位置、尺寸与触摸形状都由画布几何与形变参数推导，不出现与设备相关的常量

弹簧积分器只用在设置页分段控件的指示块上，桌宠的位移、尺寸与透明度都走定时补间。

## 与原挂件的对应关系

保留：余额接口与多币种选取顺序、峰谷定价表与时段判定、记账规则、随机台词与权重、峰谷文案三档、
气泡几何与描边配色、按压回弹、左吸附镜像、数字滚动、刷新节奏、音效集合、台词与错误文案。

替代：浏览器窗口吸附改为屏幕吸附并叠加安全区，右键菜单改为设置界面，
「每轮对话消耗」在手机端没有对应事件，改为刷新检测到余额下降时弹出的消耗气泡；
避让滚动条仅在桌面端有意义，未移植。

## 已知限制

- 鲸鱼与气泡各占一个矩形窗口，窗口分别收紧到各自实际绘制的范围；
  命中判定按绘制像素进行（鲸鱼读贴图透明度，气泡读三个图形的绘制掩码）。
  窗口内没有绘制到的像素（外框余量、鱼鳍之间的空隙、气泡外接矩形的四个角）
  不会响应，也不会继续传给下层应用，这是单矩形窗口的固有限制。
- 显示桌宠需要悬浮窗权限，未授权时打开开关会先跳转授权页。
- 后台保活依赖前台服务与电池优化白名单，设置页提供两个跳转入口；
  国产系统的自启动与后台限制还需在系统设置里单独放行。
